# Team Knowledge Base

团队共享知识库 —— 用于沉淀 AI 验证开发领域的知识框架、Qoder Skill、演示材料等。

## 目录结构

```
team-knowledge/
├── knowledge/                # 知识框架文档
│   ├── ai-coding/            # AI 辅助开发经验
│   ├── specs/                # 官方规范 PDF（AMBA CHI、RISC-V 等）
│   └── verification/         # 验证方法论
├── skills/
│   └── custom/               # 团队自定义 Qoder Skill
├── slides/                   # 演示材料（HTML slide 等）
├── templates/                # 通用模板
├── docs/                     # 使用指南和文档
└── README.md
```

## 快速开始

```bash
git clone https://github.com/<YOUR_ORG>/team-knowledge.git
cd team-knowledge
```

## 如何贡献

1. 创建分支：`git checkout -b feat/your-topic`
2. 编写内容并本地确认
3. 提交 PR，请同事 review 后合并
